# Code of conduct

Mnemosyne has one maintainer and does not take external code contributions, so
this is short.

In issues, discussions, and any other space tied to this project: be civil, stay
on the topic, and assume good faith. No harassment, no personal attacks, no
spam.

The maintainer moderates these spaces and may edit, lock, or delete anything
that breaks the above, and may block a repeat offender.

Report a problem to nabilshahx@gmail.com.
